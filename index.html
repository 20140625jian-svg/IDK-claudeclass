01

Claude Code

Claude Code는 말로 부탁하면 코드를 읽고, 만들고, 실행까지 해 주는 AI 코딩 도우미입니다. claude.ai/code에서 시작하면 클라우드 컴퓨터에서 작업합니다.

  • 한국어로 부탁하면 됩니다. 예: “간단한 웹페이지 만들어 줘”
  • 클라우드 세션은 내 Mac과 다른 컴퓨터입니다. 결과물은 GitHub에 올려야 남고, 내 Mac으로 가져올 수 있습니다.
  • 내 Mac에서 해야 하는 일(설치, 로그인)은 Claude가 명령어를 알려 주고 내가 직접 실행합니다.

02

GitHub 연결하기

내 Mac에 GitHub CLI(gh)를 설치하고 로그인합니다.

  1. Git 확인

    git --version

  2. GitHub CLI 설치

    Homebrew가 없으면 GitHub 릴리스 페이지에서 gh_버전_macOS_universal.pkg를 받아 설치합니다. 실행이 막히면 파일을 우클릭 → 열기.

    gh --version

  3. 로그인

    gh auth login --web

    8자리 코드를 복사 → Enter → 브라우저에 붙여넣기 → Authorize. 질문에는 GitHub.com → HTTPS → Yes.

  4. 내 이름과 이메일 등록

    git config --global user.name "내 이름"
git config --global user.email "GitHub 이메일"

  5. Claude와 GitHub 연결

    claude.ai/connect-github에서 연결해야 Claude Code가 내 저장소에 올릴 수 있습니다.

03

GitHub에 레포 만들기

레포(저장소)는 프로젝트 파일과 변경 기록을 담는 폴더입니다.

  1. github.com에서 만들기

    오른쪽 위 + → New repository → 이름 입력 → Add a README 체크 → Create repository.

  2. 또는 터미널에서 만들기

    gh repo create IDK-claudeclass --public --add-readme

  3. Claude Code에 연결

    레포 주소를 주고 부탁합니다. 예: “https://github.com/내아이디/IDK-claudeclass 이 레포 연결해”

04

로컬에 연결하기

GitHub에 있는 레포를 내 Mac 바탕화면으로 복사(클론)합니다.

  1. 바탕화면에 클론

    gh repo clone 내아이디/IDK-claudeclass ~/Desktop/IDK-claudeclass

  2. 새로 바뀐 내용 가져오기

    cd ~/Desktop/IDK-claudeclass
git pull

05

간단한 웹페이지 만들기

Claude Code에게 부탁하면 index.html(내용)과 style.css(디자인)를 만들어 줍니다.

  1. 부탁하기

    “간단한 웹페이지 만들어 줘” → 미리보기 확인 → “커밋하고 푸시해”

  2. 내 Mac에서 열어 보기

    cd ~/Desktop/IDK-claudeclass
git pull
open index.html

자주 쓰는 명령어

git status

바뀐 파일 확인

git add .

변경 사항 담기

git commit -m "메시지"

저장 지점 만들기

git push

git pull
